🔗双人共享（仅体重与今日消耗）

开启后，两台设备会自动互相同步「体重 / 腰围」与「跳操消耗」，用于首页的当日体重与今日消耗对照；饮食、喝水、三餐照片、留言和设置仍各自保存在本机，不会上传。

Token 怎么创建？点开看 4 步 ♡
1. 登录 GitHub → 右上角头像 → Settings → 最底部 Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic)。
2. 备注随意，有效期选 No expiration（或 90 天），权限只勾 gist，其余一律不勾。
3. 点 Generate token，复制一次显示的 ghp_... 粘到上面输入框。Token 只能由你本人在网页生成，助手无法代生成。
4. 点「创建共享房间」→ 邀请链接自动复制，发给同伴；同伴粘贴到第 ② 步加入即可。凭证只存在各自浏览器，链接请勿发到公开场合。

📦本机数据管理

饮食、饮水、三餐照片、留言与设置只保存在当前浏览器；体重、腰围与跳操消耗会按上方共享设置同步。开启共享前的本机记录会自动带入房间，不会丢失。

提示：清除浏览器数据会一并清除本机记录，建议每周导出一次 JSON 备份；换设备时用「导出 / 导入备份」迁移。本工具为日常记录参考，不构成医疗或营养建议。

🤖AI 看图估算（可选）

默认零配置即可使用（内置食物库点选）。若你有兼容 OpenAI 格式的视觉模型接口，填写后上传照片即可自动识别食物并填入热量。凭证只保存在本机浏览器，不会上传或同步。

浏览器会直接把照片发给该接口，请确认你信任该服务商；能否跨域取决于服务商。未配置或调用失败时会自动回退到内置食物库，不影响其他功能。

💡使用说明

1. 页面是单人视角：饮食、喝水、跳操流水、体重趋势、看板都只显示「我」的记录；首页的「当日体重」与「今日消耗」两块同时显示两人数据。
2. 两人各用各设备时，由一人在「设置 → 双人共享」创建房间并把邀请链接发给对方；对方粘贴加入后，两人自动对应「我 / 对方」两个身份。
3. 只有体重 / 腰围与跳操消耗会同步；饮食、喝水、三餐照片、留言与设置始终留在各自设备。身份首次确认后锁定，不能自由切换到对方；选错了可用下方「更正我的身份」。
4. 体重精确到小数点后两位，腰围可单独记录；两者建议每天固定时段测量，饮食推荐按日期自动轮换。
5. 首页体重卡片下方给出「较起始」「较昨日」两组对比；昨日未称时自动改用最近一次记录并标注日期。
6. 「饮食 → 三餐照片」可上传照片、点选食物自动估算热量并生成建议；照片压缩后保存在本机，不会上传，也可配置视觉模型接口自动看图识别。
7. 每杯水容量与每日饮水目标可在「设置 → 目标设置」里修改，默认每杯 500 ml、每日 2000 ml（约 4 杯）。
8. 左侧「经期」可记录最近一次月经开始日与周期长度；「经期前三天」按你的定义指经期开始第一天往后数的 3 天（经期第 1–3 天），这 3 天会自动标为休息窗口，跳操打卡会提示按约定休息。经期记录只保存在本机，不会同步给对方。
9. 跳操打卡可选择日期，支持补录过去漏记的记录；下方「打卡日历与统计」按月显示每天的消耗深浅，并汇总当月打卡天数、连续天数、累计打卡与平均每次消耗。
10. 「跳操打卡 → 操课类型」不再预置课程，直接输入自己的课程名即可；输入过的会自动记入课程库，之后可从下拉候选里选。热量先按名字匹配常见 MET，匹配不到按中等强度 6.0 估算，也可直接填实测消耗。
11. 首页「今日热量」的每日摄入额度默认按公式自动估算，点中间圆环可改成自定义固定值或仅当日调整，设置只存本机。
12. 首页「今日热量」点「📷 拍照识别食物」即可在首页完成拍照、识别食物名称与热量、记入当日摄入；真正的自动识别需在弹窗里配置一次视觉模型接口，零配置时可用食物库点选或把照片发到对话让助手识别后粘贴结果。
13. 首页「今日热量」下方点「早餐 / 午餐 / 晚餐 / 加餐」格子，可直接输入食物名称与热量连续记录多样，并显示该餐小计；「运动」格子已移除，运动消耗仍在上方数字里查看。
14. 首页「体重」卡可同时记录体重与腰围并显示目标进度条；左侧「体重」页展示体重 / 腰围双线趋势图（左轴 kg、右轴 cm）、体重日历与折叠的记录明细。
15. 全站「较起始」统一以「设置 → 我的档案 → 起始体重」为基准（未填时才回退到第一次称重记录），体重卡、对比表、目标进度条与体重页四处一致，并在数字旁标出基准值；补录更早的称重不会改变这个基准。
16. 全站运动消耗统一按 1 碗熟米饭 ≈ 200 kcal 并列换算为米饭碗数，方便直观理解；饮食摄入热量不做换算。
17. 本工具为日常记录与一般性参考，不构成医疗、营养或运动处方建议。
